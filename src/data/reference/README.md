# Country reference data

`countries.csv` is a small operational seed used to configure the current
Algeria trade-data workflow and its mirror reporter priority. It contains five
rows and is not a complete country catalog.

The repository currently does not record a source URL, retrieval date, or
verification evidence for these rows. Treat the dataset as unverified
configuration until its country codes and coverage are checked against
authoritative source material. Do not use it as a stand-alone source for
country facts or as a complete list of eligible mirror reporters.

When this dataset is expanded, retain per-field source or dataset-level
provenance, an access date, and a documented update process.
