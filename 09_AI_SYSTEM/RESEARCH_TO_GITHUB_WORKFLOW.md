# ACCESS ALGERIA
# RESEARCH TO GITHUB WORKFLOW

> Standard workflow for converting research into structured organizational knowledge.

---

# 1. PURPOSE

Research should not remain isolated inside an AI conversation.

Relevant and validated findings should be converted into reusable Access Algeria knowledge.

---

# 2. WORKFLOW

RESEARCH QUESTION
↓
SOURCE DISCOVERY
↓
SOURCE REVIEW
↓
FACT EXTRACTION
↓
VERIFICATION
↓
CLASSIFICATION
↓
GITHUB STORAGE

---

# 3. STEP 1 — DEFINE THE QUESTION

Every research activity should begin with a clear question.

Example:

What evidence supports the potential for this brand to enter Algeria?

---

# 4. STEP 2 — DISCOVER SOURCES

Use appropriate research systems to identify relevant sources.

Prioritize:

- Official sources
- Primary sources
- Current sources
- High-authority sources

---

# 5. STEP 3 — EXTRACT RELEVANT INFORMATION

Extract only information relevant to the decision or project.

Avoid collecting information without strategic purpose.

---

# 6. STEP 4 — VERIFY

Classify findings as:

- Verified
- Sourced
- Under Verification
- Assumption

---

# 7. STEP 5 — CLASSIFY

Determine the appropriate destination:

Market Intelligence

Brand Database

Regulatory Intelligence

Partnership Intelligence

Project Case

---

# 8. STEP 6 — STORE IN GITHUB

Store the information in the relevant file.

Each important finding should maintain:

- Source
- Date
- Context
- Verification status

---

# 9. CORE RULE

GitHub should contain structured knowledge.

It should not become a repository of uncontrolled AI outputs.
