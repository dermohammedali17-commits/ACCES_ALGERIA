# ACCESS ALGERIA
# AI PROMPT ARCHITECTURE

> A standardized architecture for creating reliable AI prompts across Access Algeria.

---

# 1. PURPOSE

This framework defines how prompts should be structured when using AI systems for research, analysis and strategic work.

The objective is to improve:

- Consistency
- Accuracy
- Context awareness
- Output quality
- Reusability

---

# 2. STANDARD PROMPT STRUCTURE

A professional prompt should contain:

CONTEXT
↓
ROLE
↓
OBJECTIVE
↓
INPUT
↓
TASK
↓
CONSTRAINTS
↓
OUTPUT FORMAT

---

# 3. CONTEXT

Define the relevant project context.

Example:

Access Algeria is a market-entry and business development platform focused on helping international companies navigate opportunities in Algeria.

---

# 4. ROLE

Define the required expertise.

Example:

Act as a senior market-entry strategist with expertise in Algeria, international business development and strategic partnerships.

---

# 5. OBJECTIVE

Clearly define the desired outcome.

Avoid vague instructions.

---

# 6. INPUT

Provide:

- Verified facts
- Sources
- Project information
- Existing analysis
- Known assumptions

---

# 7. TASK

Define the exact work required.

Examples:

- Analyze
- Compare
- Evaluate
- Identify
- Structure
- Recommend

---

# 8. CONSTRAINTS

Specify important limitations.

Examples:

- Do not invent facts
- Separate facts from assumptions
- Identify missing information
- Flag uncertainty
- Prioritize evidence

---

# 9. OUTPUT FORMAT

Specify the required structure.

Example:

1. Executive Summary
2. Key Findings
3. Strategic Analysis
4. Risks
5. Recommendation
6. Next Actions

---

# 10. PROMPT QUALITY CHECK

Before using an important prompt, verify:

- Is the objective clear?
- Is sufficient context provided?
- Is the task specific?
- Are constraints defined?
- Is the output format useful?
