## DEPENDENCY PRINCIPLE

A system should depend only on information that is necessary for its function.

Unnecessary cross-dependencies should be avoided.

---

## CRITICAL DEPENDENCIES

### Governance → Intelligence

Unverified information should not become strategic intelligence.

### Intelligence → Scoring

Opportunity scoring should use structured evidence.

### Scoring → Market Entry

Market-entry strategy should reflect opportunity quality.

### Strategy → Execution

Execution should follow approved strategic decisions.

### Execution → Performance

Results should feed performance measurement.

### Performance → Knowledge

Lessons should improve future decisions.
