## 2. DATA TYPES

### Raw Data

Unprocessed information collected from sources.

### Verified Data

Information that has passed the applicable verification process.

### Intelligence

Interpreted information with strategic relevance.

### Decision Data

Information used to support a documented decision.

### Execution Data

Information describing actions, owners, deadlines and outcomes.

### Performance Data

Information used to measure results.

### Knowledge

Reusable information generated through research and experience.

---

## 3. DATA QUALITY RULES

Information should be:

- Traceable
- Relevant
- Current where required
- Properly classified
- Appropriately verified
- Connected to its source
- Updated when material changes occur
