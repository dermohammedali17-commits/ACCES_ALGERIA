# ACCESS ALGERIA
# TASK MANAGEMENT STANDARD

> Standard rules for creating and managing execution tasks.

---

# 1. TASK REQUIREMENT

Every task should contain:

- Clear Action
- Expected Outcome
- Owner
- Priority
- Deadline
- Status

---

# 2. TASK NAMING

Tasks should begin with an action.

Examples:

- Research
- Verify
- Analyze
- Contact
- Prepare
- Review
- Approve
- Develop

Avoid vague task names.

Bad example:

Market Research

Better example:

Research luxury automotive demand indicators in Algeria.

---

# 3. TASK PRIORITY

Use:

- CRITICAL
- HIGH
- MEDIUM
- LOW

---

# 4. TASK STATUS

Use:

- NOT STARTED
- IN PROGRESS
- WAITING
- BLOCKED
- REVIEW
- COMPLETED

---

# 5. TASK COMPLETION

A task should not be marked completed unless:

- The required action is finished
- The output exists
- The result has been recorded

---

# 6. BLOCKED TASKS

Blocked tasks should identify:

- What is blocked
- Why it is blocked
- What is required
- Who is responsible for resolving the issue

---

# 7. CORE RULE

Activity is not progress.

Only completed outputs should be treated as measurable progress.
