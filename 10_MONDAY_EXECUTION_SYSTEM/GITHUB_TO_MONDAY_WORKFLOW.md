# GITHUB TO MONDAY WORKFLOW

> Standard workflow for converting structured knowledge into execution.

---

# 1. PURPOSE

Not every piece of information stored in GitHub becomes a task.

Only approved actions requiring execution should be transferred to Monday.

---

# 2. WORKFLOW

GITHUB
↓
FINDING
↓
ANALYSIS
↓
RECOMMENDATION
↓
DECISION
↓
MONDAY TASK
↓
EXECUTION
↓
RESULT
↓
GITHUB UPDATE

---

# 3. TRANSFER TO MONDAY

Create a Monday task when there is:

- A clear action
- An expected outcome
- A responsible owner
- A relevant project or objective

---

# 4. TASK REFERENCE

Each important task should reference:

- Related Project
- Related Brand
- Related Partner
- Related GitHub Document

---

# 5. EXECUTION RESULT

After completing an important task:

1. Record the execution result
2. Update the relevant project status
3. Update GitHub when new knowledge or decisions were produced

---

# 6. EXAMPLE

GitHub Finding:

A brand demonstrates potential interest in regional expansion.

Decision:

Research the Algeria opportunity further.

Monday Task:

Research the brand's expansion strategy and identify the appropriate business development contact.

Result:

Findings are documented.

GitHub is updated with validated knowledge.

---

# 7. CORE PRINCIPLE

GitHub preserves organizational knowledge.

Monday manages organizational action.

Both systems must remain connected.
