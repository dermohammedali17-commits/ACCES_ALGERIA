# ACCESS ALGERIA
# NAMING STANDARDS

---

## 1. FOLDER NAMING

Main system folders should follow:

NN_SYSTEM_NAME

Example:

00_MASTER_CONTROL

01_GOVERNANCE_AND_VERIFICATION

02_MARKET_INTELLIGENCE

---

## 2. FILE NAMING

Files should use:

UPPERCASE_WORDS_WITH_UNDERSCORES.md

Example:

PROJECT_SCOPE.md

BUSINESS_MODEL.md

MARKET_ENTRY_STRATEGY.md

---

## 3. AVOID

Do not use:

- Random numbering
- Duplicate names
- Unclear names
- Spaces when unnecessary
- Temporary names for permanent documents

---

## 4. CONSISTENCY

The same type of document should use the same naming logic across the repository.

---

## 5. FINAL RULE

A file name should make its purpose understandable before opening the file.
