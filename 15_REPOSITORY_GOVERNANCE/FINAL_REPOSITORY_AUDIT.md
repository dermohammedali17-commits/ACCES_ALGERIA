# 3. AUDIT CLASSIFICATION

Each repository item must be classified as one of:

### KEEP

Correct, relevant and structurally appropriate.

### RENAME

Correct content but incorrect naming.

### MOVE

Correct content but located in the wrong system.

### MERGE

Duplicate or overlapping content that should be consolidated.

### ARCHIVE

Historically relevant but no longer operationally active.

### DELETE

Confirmed unnecessary, duplicate or invalid content.

### REVIEW

Cannot be classified safely without inspecting its content.

---

# 4. AUDIT PRINCIPLES

- Do not delete without inspection.
- Do not create unnecessary duplicates.
- Preserve valuable historical information.
- Maintain one source of truth.
- Correct naming inconsistencies.
- Keep systems functionally distinct.
- Prefer integration over duplication.
- Record material structural changes.
- Validate dependencies before moving files.
