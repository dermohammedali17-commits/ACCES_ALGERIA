# ACCESS ALGERIA
# ASSUMPTIONS REGISTER

> A structured register for assumptions that may influence strategic decisions.

---

# 1. PURPOSE

This register tracks assumptions used during research, strategy development and project planning.

The purpose is to prevent assumptions from being treated as verified facts.

---

# 2. ASSUMPTION RECORD

Each important assumption should include:

- Assumption ID
- Description
- Related Project
- Strategic Impact
- Evidence Available
- Confidence Level
- Validation Required
- Owner
- Status

---

# 3. ASSUMPTION STATUS

- ACTIVE
- UNDER VALIDATION
- VALIDATED
- REJECTED
- NO LONGER RELEVANT

---

# 4. STRATEGIC IMPACT

Assumptions should be classified as:

- LOW
- MEDIUM
- HIGH
- CRITICAL

Critical assumptions must be validated before major decisions are made.

# 6. CORE RULE

It becomes more credible only when supported by evidence.
